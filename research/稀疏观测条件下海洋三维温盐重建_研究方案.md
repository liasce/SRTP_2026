# 稀疏剖面与海表观测融合的热带太平洋三维温盐重建

> 论文级研究设计稿 · 2026-09-11
> 本文规定研究问题、数据角色、实验顺序和结论边界。当前没有正式模型结果，所有贡献均为待检验假设。

## 1. 研究定位

### 1.1 研究对象

研究区域为20°S–20°N、120°E–80°W的热带太平洋，目标是在月尺度上，根据当月稀疏温盐剖面和可用海表观测，估计5–500 m的三维保守温度（CT）与绝对盐度（SA）场。首版沿用已验收的CORA对齐网格：经度120–280°E、0.5°间隔，纬度保留CORA在约19.61°S–19.61°N之间的81个非均匀坐标；距离和面积一律按实际经纬度计算。垂向固定为60层：5–100 m每5 m一层，110–500 m每10 m一层。输出是当月代表状态，不是未来预测，也不试图恢复月内瞬时过程。

本研究不把CORA当作真实海洋。CORA提供规则网格监督、训练期背景统计和误差描述；严格未输入的Argo剖面承担温盐与密度评价，未参与模型选择的TAO/TRITON系泊承担温跃层评价。不同资料提供不同层级证据，没有任何一项等同于完整三维真值。

### 1.2 中心科学问题

> 在固定的同期稀疏剖面预算下，海表信息与数据驱动空间先验能否相对于纯海表估计和同观测最优插值，提高未观测位置的温盐与密度估计；这种增益在多大距离、哪些深度和何种气候状态下仍然存在？

这个问题比“哪种网络RMSE最低”更接近研究意义。若复杂模型不能超过使用相同剖面的合理最优插值，说明同期剖面有信息，但学习型融合没有证明额外价值。若增益只存在于特定距离或深度，适用边界本身就是结果。

### 1.3 论文候选贡献

1. 在真实稀疏观测几何下，量化同期剖面相对纯海表估计的增量，以及学习型融合相对同观测OI的额外增量。
2. 给出增益随距最近输入剖面的距离、深度、季节和ENSO状态变化的经验边界，而不是只报告全域平均误差。
3. 检验CORA网格预训练能否迁移为严格未输入剖面上的收益；若不能，只将其解释为参考产品拟合。
4. 仅在作用空间充分时，检验静力稳定软约束是否改善未直接优化的科学量，并与一般平滑和事后稳定化区分。

上述内容均为候选贡献，不使用“首次”“全面优于”或“恢复真实海洋”等表述。新颖性最终取决于最近邻文献复核和实验结果。

## 2. 假设与反证

### H1：稀疏观测融合具有超出传统插值的增量技能

在相同海表数据、相同输入Argo清单和相同隐藏评价池下，融合模型在隐藏Argo的CT和SA上优于纯海表模型与同观测OI；增益随距离和深度变化，但在预先规定的支持范围内保持稳定方向。

反证包括：融合模型只优于纯海表而不优于OI；收益仅来自少数海区或个别月份；输入Argo附近改善但稍远即消失；温度改善而盐度明显退化。

### H2：网格预训练能够迁移到原位观测

在近期训练数据、更新步数和模型结构相同的条件下，长期CORA预训练后再进行近期观测融合训练，相对于近期从头训练，在隐藏Argo或TAO上获得稳定收益，而不只是更接近CORA。

反证包括：收益只存在于CORA网格误差；2005年开始的长历史不优于2010年开始；预训练提高平均精度却恶化事件期或早期观测稀疏区。

### H3：静力稳定约束存在可辨识的附加作用

仅当无物理模型产生足够数量和幅度的非物理倒置时，训练内稳定性约束才进入实验。若进入，要求它在相近温盐误差或相近稳定化强度下，优于垂向平滑和事后稳定化，并改善D20、密度结构或其他未直接优化量。

反证包括：强负N²事件过少；约束只减少直接优化的倒置率；作用可由普通平滑完全解释；温盐、温跃层梯度或异常幅度受到明显损害。

H1是论文主假设，H2是方法子假设，H3是条件性子假设。H1失败时不通过增加Swin模块或物理损失挽救主张。

CORA分析的候选观测时间可跨月，因此每个“训练→验证”边界保留一个隔离月；并用CORA `dat`文件审计实际支持日期。验证早停和选模以E平台原位误差为准，不把验证期CORA网格误差作为主要选择信号。若产品文档和`dat`审计不能证明更短支持范围，不取消隔离月。

2018全年被定义为工程开发集，用于验证下载、角色划分、OI和模型管线。它属于训练期，使用它选择工程实现后不能再作为独立验证证据。

### 3.2 月份和历史输入

主任务输出月份为t。海表输入使用t−2、t−1和t三个月的SST、ADT和风，稀疏Argo仅使用t月；2015年后SSS采用相同历史窗口。每个时间段额外下载前两个月作为输入缓冲，但它们不进入标签或评价。这样仍是同期重建，因为预测目标时这些历史观测已经存在。设置仅使用t月海表的消融，判断历史记忆是否必要。

所有月场聚合、异常背景和时间窗口在测试前冻结。Argo保留距月中日期偏移，评价时报告时间匹配敏感性，不能把瞬时剖面与月平均场的差异全部归因于模型。

## 4. 剖面角色和泄漏控制

### 4.1 三种剖面角色

1. **上下文剖面C**：作为模型和OI的当月输入。
2. **训练目标剖面Q**：用于原位损失，但在该训练样本中不作为输入，避免模型在输入点直接复制。
3. **评价平台E**：按平台号在全研究期固定留出，不进入稀疏输入或原位损失，只用于验证和测试。

E由WMO编号的固定哈希规则产生，不根据未来覆盖或模型误差挑选；空间分布失衡仅在开发期资料中审计并预先规定报告权重。在训练月份内，非评价平台的剖面按固定随机种子轮换为C和Q；同一月份内C、Q、E互不相交，每个样本保存清单。训练期某平台在不同月份轮换C/Q不构成评价泄漏，E平台则全期不轮换。所有模型和OI使用相同C，所有方法在相同E上评价。空间切块必须在角色确定后进行，重叠块不能改变剖面身份。

正式稀疏度实验在C中保留25%、50%和100%的候选剖面；E始终不变。抽稀清单至少生成三组重复，但模型选择只使用预先指定的开发规则。

### 4.2 CORA同源性的处理

CORA分析可能使用Argo和其他原位资料，因此“CORA监督＋Argo评价”不是端到端来源独立。控制方式是：

- 测试月份的CORA不进入模型、背景拟合或调参；
- E平台不直接进入模型输入和原位损失；
- CORA与E的一致性只称产品一致性，不称独立精度；
- TAO不参与训练和模型选择，但仍审计其是否可能进入CORA或海表产品；
- 结论限定为对未输入观测的预测技能，不升级为完整海洋真实性。

追求绝对来源独立在现有综合观测产品下并不现实。研究重点是把依赖关系说明清楚，而不是用“独立”一词掩盖上游共享。

## 5. 基线体系

### 5.1 同任务算法基线

| 编号 | 方法                     | 输入                  | 回答的问题                                 |
| ---- | ------------------------ | --------------------- | ------------------------------------------ |
| B0   | 训练期日历月气候态       | 月份、位置            | 是否只恢复季节平均                         |
| B1   | 联合T/S EOF＋岭回归      | 海表历史              | 低维可解释海表映射能做到什么程度           |
| B2   | OSnet适配版              | 海表历史、位置和月份  | 已发表且有公开代码的剖面网络能做到什么程度 |
| B3   | 局地最优插值OI           | 月背景＋当月C         | 同一稀疏观测的传统插值能力                 |
| B4   | 最佳海表基线＋OI残差修正 | 海表历史＋当月C       | 简单海表—剖面融合是否已经足够             |
| B5   | 小型CNN融合              | 海表历史＋当月C和掩膜 | 学习型融合的最低结构基线                   |

除B0外，所有海表驱动方法使用同一t−2:t信息窗口、同一缺测掩膜和同一训练月份；使用稀疏剖面的方法共享完全相同的C清单。B2只做适配统一输入所必需的修改，并同时报告其与原实现的差异。

候选Swin模型与B5只替换海表空间编码骨干，保持稀疏编码、深度解码、输出、损失、参数量和训练预算相近。若Swin没有稳定增益，最终方法使用CNN。

OSnet采用作者公开代码核对核心结构后，在统一数据上重新训练，称“adapted implementation”，不拿原论文湾流区数值直接比较。联合EOF按论文方法重实现。CLOINet任务最接近稀疏融合，但当前未核验到官方代码，首轮不投入完整重实现；获得作者代码或核心模型明显超过OI后再考虑。SwinOcean3D和Convformer没有已核验官方代码且任务输入不完全相同，只作为后续敏感性，不挤占主实验。

### 5.2 产品参照

CORA及可获得的其他分析/再分析产品单列为Reference products。它们的信息预算与算法不同，不进入“公平baseline排名”，只在共同观测位置报告一致性和结构差异。

### 5.3 当前高斯核的地位

已实现的500/1000/2000 km高斯水平插值是管线工程基准，不是正式OI。正式OI使用：

\[
\mathbf{x}_a=\mathbf{x}_b+\mathbf{C}_{go}(\mathbf{C}_{oo}+\mathbf{R})^{-1}(\mathbf{y}-\mathbf{H}\mathbf{x}_b),
\]

其中背景、协方差尺度、定位半径和观测误差只由相应训练折确定。热带太平洋应允许东西向与南北向尺度不同；首版采用局地邻域控制计算量。

## 6. 模型与监督

### 6.1 最小融合结构

模型只包含必要组件：

1. 海表编码器：处理t−2:t的SST、ADT、U/V及可用SSS和掩膜；首版使用小CNN。
2. 稀疏剖面编码器：输入当月C的CT、SA、有效掩膜、观测计数、相对月中时间及格点内经纬偏移；不得在落到网格时丢失原始观测位置。
3. 融合层：在共同水平网格合并两类特征。
4. 深度解码器：结合实际深度嵌入，一次输出60层CT和SA异常。

输出采用相对于训练期日历月背景的异常，最终场为背景与异常之和。这样训练和评价明确区分平均结构与当月异常，减少深层平稳区域支配总损失。

Swin不是预设贡献。只有小CNN超过B3/B4后，才以相同融合接口替换为小Swin并比较。

### 6.2 数据损失

\[
\mathcal L_{grid}=\frac{\sum w_g M_g\lVert\hat{\mathbf{x}}-\mathbf{x}_{CORA}\rVert_2^2}{\sum w_g M_g},
\]

\[
\mathcal L_{prof}=\frac{\sum M_Q\lVert H_Q\hat{\mathbf{x}}-\mathbf{y}_Q\rVert_1}{\sum M_Q},
\qquad
\mathcal L=\mathcal L_{grid}+\lambda_A\mathcal L_{prof}.
\]

\(M_g\)和\(M_Q\)分别是CORA网格与Q的有效掩膜，\(w_g\)是由CORA误差场得到的有界权重；\(H_Q\)把网格输出采样到目标剖面位置。极小误差不得产生无限权重。温度和盐度分别按训练期尺度标准化，评价回到物理单位。

Q不作为同一样本的输入，这一点比在输入Argo上计算辅助损失更能检验空间传播。若仅在C点计算原位损失，必须单列为复制锚定消融，不作为主监督。

### 6.3 训练策略

第一轮只比较两个策略。两者使用相同的近期训练月份、微调更新步数、早停规则和随机种子；预训练本身是S1的处理因素，其额外计算量另行报告，不用“总计算量相等”掩盖该差异：

- S0：2015-04—2020-11近期完整模态从头训练；
- S1：2005-01—2015-03共同模态预训练，随后在2015-04—2020-11进行完整模态联合微调。

若S1在隐藏观测上稳定优于S0，再比较2010起点和“联合损失微调/仅Argo微调”。若无收益，删除长期阶段，不继续穷举预训练长度。

SSS在长期阶段不存在时使用缺测通道和可用性掩膜；更简单的主实现是在预训练阶段关闭SSS通道，在微调阶段通过独立输入投影加入。两种方案只保留验证更稳定且实现更简单者。

## 7. 物理诊断与条件性约束

海水密度和浮力频率按TEOS-10计算：

\[
\rho=\rho(S_A,CT,p),\qquad
N^2=g^2\frac{\beta\Delta S_A-\alpha\Delta CT}{v\Delta P}.
\]

深度向下为正，层间差取深层减浅层；GSW输入压力使用dbar，公式中的\(\Delta P\)使用Pa。温度和盐度均不施加单调硬约束。

候选稳定损失为：

\[
\mathcal L_{stable}=\left\langle\left[\frac{\max(0,-N^2-\epsilon_N)}{N^2_{scale}}\right]^2\right\rangle.
\]

进入训练前必须完成go/no-go：在多月份CORA和无物理B5上统计负N²比例、强度、深度和容差敏感性。现有两月CORA普通负N²约2%–3%，但\(N^2<-10^{-4}\,s^{-2}\)仅约0.05%–0.09%，因此H3目前更可能被降为补充实验。

若进入，比较无约束、按实际层距的垂向曲率平滑、事后最小改动稳定化和训练内N²约束。只有在未直接优化的D20或密度结构改善、温盐不明显退化且优于平滑时，才能讨论物理可信度提高。

## 8. 评价指标与统计单位

### 8.1 主要评价

主要证据来自E平台隐藏Argo：

- CT和SA的RMSE、MAE与偏差，分别报告物理单位；
- 相对于B0的异常技能；
- 由CT/SA诊断的\(\sigma_0\)误差；
- 5–50、50–150、150–300和300–500 m分层结果；
- 距最近C的0–250、250–500、500–1000和>1000 km结果。

距离箱若在开发资料中支持不足，应在查看测试结果前合并并记录。单个深度层不是独立重复：先按剖面汇总，再按平台和月份进入统计。

主比较是B5/候选模型相对于B3和B4的配对误差差值。CT与SA作为共同主要结果分别报告，不用任意加权合并成一个分数掩盖此消彼长。H1只有在CT和SA点估计均不恶化、至少一项相对B3和B4的95%置信区间排除零改善，且另一项满足测试前冻结的非劣界限时才获得支持；非劣界限依据开发期观测代表性误差和用途确定，不从测试结果反推。

### 8.2 科学量评价

- TAO主评D20：预测CT结合SA和压力转为原位温度，寻找20°C交点；无交点和多交点进入失败率。
- 密度MLD和5–300 m异常热含量为探索性指标，只有共同T/S与垂向覆盖通过审计才进入主文。
- N²报告倒置比例、负值幅度和过度平滑诊断；其下降本身不证明科学价值。

TAO深层盐度稀疏，不能用温度覆盖替代联合T/S证据。暖池主测试期若无足够系泊，明确缩小TAO结论范围，以隐藏Argo承担西太平洋温盐评价。

### 8.3 统计推断

所有方法在同一观测上配对。先按平台—月份聚合，再进行连续时间块bootstrap；3个月为起点，6个月为敏感性。空间上按平台或邻近平台组重采样。报告95%置信区间、平台数、月份数、有效剖面数和失败原因。

主要学习模型最终使用5个配对随机种子；种子差异和海洋采样不确定性分开报告。大量格点、深度层或随机种子不能替代独立月份和平台。

## 9. 最小实验闭环与退出门

| 阶段          | 比较                                 | 继续条件                                       | 失败后的处理                     |
| ------------- | ------------------------------------ | ---------------------------------------------- | -------------------------------- |
| E0 数据与基准 | 2018全年B0、核插值、正式OI           | 角色零交叉、OI参数仅来自开发资料、评价分母稳定 | 修数据和评价，不训练网络         |
| E1 信息价值   | B0–B5；50%稀疏度为主                | B5相对B3/B4在隐藏CT/SA上有稳定增量             | 停止Swin和物理实验，简化或重定位 |
| E2 预训练     | S0与S1；2010起点敏感性后置           | S1在隐藏观测和时间滚动折上有一致收益           | 删除长期预训练主张               |
| E3 架构       | 小CNN与参数相近小Swin                | Swin收益超过种子和时间折不确定性               | 最终使用CNN，不保留Swin题目      |
| E4 适用边界   | 25/50/100% C；距离、深度、季节、ENSO | 支持足以估计增益曲线                           | 只报告有支持区域，不外推         |
| E5 条件物理   | 无约束、平滑、事后稳定化、N²        | go/no-go通过且未优化科学量改善                 | N²只作诊断或删除                |
| E6 锁模测试   | 2023–2024隐藏Argo与TAO              | 按冻结协议一次运行                             | 如实报告负结果，不回到测试集调参 |

第一篇论文不同时承担模型开发、资料产品发布、物理机制发现和观测系统优化。最低可发表闭环是：公平基线、真实隐藏观测、观测增量、距离—深度边界和诚实的不确定性。H2与H3只有在通过退出门后才进入标题或摘要。

## 10. 结论规则

| 观察结果                                  | 允许的结论                                     |
| ----------------------------------------- | ---------------------------------------------- |
| 融合优于纯海表，但不优于同观测OI          | 同期剖面提供信息；学习型融合附加价值未证明     |
| 融合优于OI，但不优于最佳海表背景＋OI      | 海表背景有价值；端到端融合优势未证明           |
| 融合稳定优于B3/B4，且增益有距离—深度边界 | 支持限定观测条件下的学习型融合贡献             |
| CORA预训练只改善CORA误差                  | 学习了参考产品，不支持原位迁移贡献             |
| N²减少而隐藏T/S或D20不改善               | 只支持数值稳定化，不支持整体物理可信度提高     |
| 科学量改善但不超过平滑/后处理             | 一般垂向正则或校正有效，物理约束附加价值未证明 |
| TAO盐度或暖池覆盖不足                     | 缩小结论范围，不用温度或其他海区代替           |
| 所有复杂模型不优于B4                      | 采用简单方法，论文转为信息上限与失败边界研究   |

## 11. 对既有对话注意力偏差的纠正

| 曾经的偏移                       | 对设计造成的风险                        | 当前纠正                                             |
| -------------------------------- | --------------------------------------- | ---------------------------------------------------- |
| 以Swin命名项目                   | 在证明任务价值前预设架构结论            | 题目方法中性；CNN通过后才比较Swin                    |
| 将N²视为唯一核心创新            | 对月平均平滑场可能是近似空干预          | H3降为go/no-go后的条件实验                           |
| 把CORA称作真值或必须超过的对象   | 混淆监督产品、真实海洋和信息预算        | CORA只作训练参考和产品参照                           |
| 追求“完全独立”表述             | 忽视综合产品不可避免的上游共享          | 改用角色隔离、来源审计和分级证据                     |
| 用模块组合定义创新               | Swin、Argo融合、TEOS-10和预训练均有先例 | 创新改为观测增量及其适用边界                         |
| 同时强调D20、MLD、OHC、N²       | 指标过多且观测支撑不同                  | CT/SA/密度为主，D20确认，MLD/OHC探索                 |
| 过早扩大到2005年和全量下载       | 数据规模替代了假设检验                  | 先用2018全年闭合OI和最小模型，再决定长期段           |
| 用拉尼娜验证、厄尔尼诺测试讲泛化 | 单次事件可能支配结论                    | 增加训练期滚动验证，测试结论限定事件范围             |
| 在输入Argo点计算主要辅助损失     | 模型可通过复制输入获得虚假训练收益      | 将训练剖面拆为上下文C和非输入目标Q                   |
| 忽略CORA跨月分析支持             | 名义时间分割仍可能在边界共享观测        | 训练边界留一月隔离，并审计`dat`支持日期            |
| 将剖面粗格点化后与OI比较         | 模型因丢失亚网格位置而获得不公平劣势    | 保留原始位置及格点内偏移，OI与模型共享同一C          |
| 用全域均值掩盖Argo采样偏置       | 高观测密度区可能主导“总体改善”        | 同时报平台加权、区域分层和有效支持，不外推无支持海区 |
| 持续增加文档和实验矩阵           | 计划复杂度超过实证进度                  | 保留一个主设计、一个状态入口，按退出门执行           |
