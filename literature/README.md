## 1. 结论先行

该方向在工程上可实现，在科研上仍有价值，但“把物理损失加到 Swin Transformer”本身已经不足以构成创新。现有工作已经分别证明：

- Swin/Transformer 能够从多源海表变量一次性重建多深度层温盐场；
- 温度梯度、密度、浮力频率、EOF 模态等先验能够改善数据驱动模型的物理一致性；
- Transformer 与物理信息的组合已经出现，包括 PGTransNet、物理引导的南海温盐重建，以及浙江大学团队的物理引导温度预测工作。

因此，本项目最合适的论文问题不是“物理约束是否有用”，而是：

> 在严格的时间外推和独立 Argo 剖面验证下，面向一次性三维温盐联合重建，差分可微的 TEOS-10 稳定层化约束能否在不牺牲温盐精度的前提下，显著降低密度倒置，并改善温跃层、异常事件和跨区域泛化？

推荐首版模型采用“二维海表网格 -> 多深度层温度与盐度联合输出”的 SwinOcean3D 范式，使用相邻深度层的离散差分构造物理损失。暂不把深度 `z` 作为连续坐标，不使用对 `z` 的 Autograd。连续坐标模型可以作为后续扩展。

## 2. 任务边界：重建与预测必须分开

当前 PPT 同时使用了“重建”“预测”两个概念。两者的数据条件和结论不同：

- 重建：用同一时刻的 SST、SSS、ADT/SSH、风场等海表信息推断该时刻的次表层温盐场。
- 预测：用历史序列预测未来一个或多个时刻的三维温盐场。

本项目首阶段应只做重建。待重建基线、物理损失和独立验证全部稳定后，再把时间维输入扩展为预测任务。这样可以避免将误差来源混合为“表层到次表层映射误差”和“时间外推误差”。

## 3. 核心文献脉络

### 3.1 三维温盐重建的模型骨架

1. **SwinOcean3D**：Wang et al. 提出 dual-residual Swin Transformer，将 Swin Transformer、U-Net、残差块和 DSCM-CBAM 组合，用 5 个海表变量一次性重建上层 1000 m 的温度或盐度。全球实验使用 1°、16 个深度层的 IPRC Argo 网格；印度洋实验使用 0.25°、47 个深度层的多模式再分析。论文报告全球温度/盐度平均 RMSE 为 0.541 °C/0.267 PSU，印度洋为 0.604 °C/0.354 PSU。重要限制是温度与盐度分开训练，且没有显式物理约束；作者把“加入物理约束”和“改善中尺度信息”列为后续方向。[论文 DOI](https://doi.org/10.1080/17538947.2025.2607902)

2. **Convformer**：Song et al. 将空间注意力与时间模块交替组合，在热带太平洋重建温盐场，报告全深度平均 RMSE 为 0.353 °C/0.0695 PSU；同时指出温跃层附近误差显著增加，极端异常事件仍是局限。[论文全文](https://www.mdpi.com/2072-4292/16/13/2422)

3. **CNN + 直接 Argo 剖面**：Smith et al. 不依赖网格化 Argo 标签，而是直接使用不规则观测剖面训练和验证 CNN，并用 Shapley 值分析海表输入贡献。这类设计对本项目的“独立剖面验证”非常重要。[论文全文](https://doi.org/10.3389/fmars.2023.1218514)

4. **高分辨率南海重建**：2025 年的涡解析 GAN 工作实现 1/12° 南海温盐反演，说明高分辨率区域实验有价值，但其标签通常来自模式/再分析，不能等同于观测真值。[论文 DOI](https://doi.org/10.1007/s00376-024-4038-5)

### 3.2 物理或知识约束

1. **浙江大学博士论文与后续 TGRS 工作**：本地博士论文提出温度梯度约束、基于 TEOS-10 的浮力频率约束，以及基于 KKT 条件的双损失动态权重。其真正实现是相邻深度层的离散差分，不是对深度坐标使用 Autograd。后续同行评审论文报告物理引导温度网络相对 CNN 提升约 20%、相对 U-Net 提升约 4%。[TGRS 论文 DOI](https://doi.org/10.1109/TGRS.2025.3622207)

2. **PGTransNet**：Wu et al. 在热带太平洋三维温盐预测中，使用温度、盐度和 TEOS-10 密度的联合损失，并加入 PDO/NPGO 嵌入和拉普拉斯位置编码。它证明了“Transformer + 温盐密度关系”的可行性，同时也意味着本项目不能仅凭这两个关键词宣称首创。论文随后发布过公式重复的勘误，使用时应引用更新版本。[论文全文](https://doi.org/10.3389/fmars.2024.1477710)；[勘误](https://doi.org/10.3389/fmars.2025.1548441)

3. **物理引导 GAN**：Meng et al. 先从数值模式学习，再用观测校准，用于南海次表层温度预测。它属于“模式先验/迁移”路线，与本项目的“显式可微物理罚项”不同，但可作为先验来源对照。[开放预印本](https://arxiv.org/abs/2111.03064)

4. **EOF 物理引导**：Zhao et al. 通过垂向 EOF 模态约束南海温盐剖面，展示了低维物理模态与深度学习融合的另一条路线。该工作也发现小数据场景下 Transformer 可能不如 CNN，提醒本项目必须保留强 CNN/U-Net 基线。[论文全文](https://www.mdpi.com/2072-4292/17/17/2954)

5. **PINNs 与自适应权重**：经典 PINN 将方程残差纳入训练；Self-Adaptive PINN 和多目标优化工作表明，多损失尺度和梯度冲突是实际训练的关键问题，而不是把几个损失简单相加。[PINNs](https://doi.org/10.1016/j.jcp.2018.10.045)；[Self-Adaptive PINN](https://arxiv.org/abs/2009.04544)；[Multi-Task as Multi-Objective Optimization](https://arxiv.org/abs/1810.04650)

### 3.3 传统统计方法仍应作为基线

EOF/mEOF、SQG-mEOF-R 和基于卫星-原位观测的统计重建方法具有低成本、可解释和强基线价值。Liu and Hu 的 2024 预印本使用多变量 EOF 从 SST/SSS/SSH 重建 0-400 m 全球温盐，但公开审稿意见质疑其新颖性、线性假设和验证策略；因此本项目可把它当作基线思路，不能把该预印本当作“物理信息深度学习已被充分验证”的证据。[预印本及公开评审](https://essd.copernicus.org/preprints/essd-2024-334/)

## 4. 对当前 PPT 技术路线的关键修正

### 4.1 Swin 输出与深度 Autograd 不兼容

SwinOcean3D 的输入是 `x[batch, surface_channels, lat, lon]`，输出是 `y[batch, variables, depth, lat, lon]`。深度在这里是输出索引，不是计算图中的连续输入，因此不能直接计算 `dT/dz`。

有两条可行路线：

- **离散层路线（首选）**：在输出的相邻深度层上计算 `(T[k+1]-T[k])/(z[k+1]-z[k])`、密度差和 `N²`。完全可微、易于与 Swin 组合。
- **连续坐标路线（后续）**：模型显式接收 `(lon, lat, z, time, surface_features)`，对连续 `z` 使用 Autograd。此时通常需要坐标网络/隐式神经表示，并使用 SiLU/Tanh 等平滑激活；它不再是原始 SwinOcean3D 的简单改造。

PPT 中“乱序全空间随机采样阻断逐层误差累积”的表述也需要删除或重新论证。一次性多层输出本来就不是逐层递推，不存在由预测层层传递造成的误差累积。随机海洋 patch 采样可以改善训练覆盖和显存占用，但不是物理定律。

### 4.2 温度随深度单调递减不是普适定律

温度逆温、混合层、季节变化和高纬过程都会导致局部违反单调递减。建议：

- 把温度梯度作为软约束，不设为硬约束；
- 使用随区域、月份和深度变化的气候态容差，而不是统一常数；
- 将其作为消融项，不把它等同于“物理正确性”；
- 主要物理指标以密度稳定性为主。

### 4.3 TEOS-10 约束的实现细节决定成败

推荐约束对象为保守温度 `CT`、绝对盐度 `SA`、压力 `p` 和位势/原位密度所构成的稳定层化指标。必须明确：

- 深度向下为正还是向上为正，避免 `N²` 符号写反；
- 实用盐度到绝对盐度、原位温度到保守温度的转换；
- 压力与纬度的关系；
- 陆地和缺测掩膜；
- 不等深层间距，不能假设 `Δz` 恒定。

常用 Python `gsw` 库以 NumPy/C 实现，通常不能直接保持 PyTorch 梯度。训练时应实现一个可微的 Torch 近似状态方程或自定义可微算子，并逐点与官方 GSW 结果做数值单元测试。官方 GSW 可用于离线标签、验证和误差审计。

### 4.4 温度、盐度应联合输出

若先训练温度再训练盐度，盐度物理损失依赖温度模型误差，且温度模型无法从密度约束中得到反向反馈。首选一个共享 Swin 编码器、两个输出头，联合预测 `T` 和 `S`：

`L = wT * L_T + wS * L_S + wN * L_N2 + wG * L_Tgrad`

其中 `L_N2 = mean(ReLU(-(N² + tolerance)))`。首轮先使用固定权重完成可复现基线；动态权重在第二轮加入。

### 4.5 KKT/动态权重不是首轮必需项

博士论文中的近似 KKT 解需要计算多个损失对网络参数的梯度，显存和时间开销较大。应依次比较：固定权重、GradNorm/不确定性权重、两目标 MGDA/KKT。若自适应方法没有在独立测试集上稳定改善数据误差和物理误差，就不应保留复杂方案。

## 5. 建议研究问题与可检验假设

### RQ1：物理约束是否改善独立测试表现？

- H1a：相对无物理约束的 SwinOcean3D，加入稳定层化损失后，独立测试集上的密度倒置率至少下降 30%。
- H1b：温度和盐度总体 RMSE 的相对退化不超过 2%，或其中至少一个显著改善。

### RQ2：改善是否集中在科学关键区域？

- H2：温跃层、强盐度梯度区和 ENSO 异常月份的 RMSE、温跃层深度误差或热含量误差改善幅度高于全域平均。

### RQ3：动态损失权重是否优于固定权重？

- H3：动态权重在至少 3 个随机种子上改善数据误差-物理误差 Pareto 前沿，而不是只改善单个运行。

### RQ4：是否具备区域/时间泛化？

- H4：在留出年份、留出经度带或留出 Argo 浮标上的性能下降显著小于纯数据驱动模型。

## 6. 推荐首版实验范围

- 任务：月尺度同步重建，不做未来预测。
- 区域：热带太平洋，建议先用 `20°S-20°N, 120°E-80°W`；资源允许后扩为 `30°S-30°N`。
- 分辨率：先用 1°，复现稳定后再提高到 0.25°。
- 深度：优先复用 SwinOcean3D 的 30-1000 m 16 层；若标签质量不足，先做 0-500 m。
- 输入：SST、SSS、ADT/SSH、10 m 风的 `u/v` 分量、月份周期编码、海陆掩膜；可选经纬度编码。
- 输出：同一网络联合输出温度和盐度。
- 标签：训练阶段可用 IPRC Argo 网格；最终评价必须加入未参与网格生成或按浮标 ID/时间留出的原始 Argo 剖面。

## 7. 数据与验证风险

1. **标签并非真值**：Argo 网格和再分析都经过插值/同化。使用同一网格训练和测试只能说明拟合该产品，不能说明恢复真实海洋。
2. **数据泄漏**：标准化统计量只能用训练期；滑动窗口不能跨越数据集边界；同一浮标相邻剖面不能同时进入训练与独立测试。
3. **时间划分**：必须按时间连续划分，不能随机打乱月份。建议训练 2010-2016、验证 2017-2018、测试 2019-2020；具体年份由所有变量共同覆盖期决定。
4. **面积权重**：全球或大区域损失需要 `cos(latitude)` 面积权重，否则高纬网格被过度计数。
5. **海陆和海底掩膜**：不同深度的有效海洋范围不同，应使用三维湿点掩膜，而不是一张二维海陆图重复到所有深度。
6. **产品漂移**：SSS 产品存在传感器更替、偏差漂移和版本变化风险，必须记录产品版本并画出时间序列质量审计图。

## 8. 基线、消融与指标

### 必做基线

1. 月气候态/WOA 或训练期均值；
2. 线性回归或 EOF/mEOF；
3. 简单 CNN/U-Net；
4. 无物理损失的 SwinOcean3D；
5. 联合 T/S 输出但无物理损失的 SwinOcean3D。

### 最小消融矩阵

| 编号 | 模型 | T 梯度 | N² 稳定性 | 权重 |
|---|---|---:|---:|---|
| A | SwinOcean3D 单任务 | 否 | 否 | - |
| B | SwinOcean3D 联合 T/S | 否 | 否 | 固定 |
| C | B + T 梯度 | 是 | 否 | 固定 |
| D | B + N² | 否 | 是 | 固定 |
| E | B + T 梯度 + N² | 是 | 是 | 固定 |
| F | E + 自适应权重 | 是 | 是 | 动态 |

每个主实验至少 3 个随机种子，报告均值与标准差。

### 数据精度指标

- 温度/盐度：RMSE、MAE、Bias、R² 或相关系数，按深度和区域分层；
- 异常场：ACC；
- 科学量：混合层深度、温跃层深度、0-300 m 海洋热含量误差；
- 极端事件：ENSO 位相、涡旋区或异常月份的条件误差。

### 物理一致性指标

- `N² < -ε` 的网格比例；
- 负 `N²` 的平均和 95% 分位幅度；
- 密度倒置层数/剖面比例；
- 相邻层 T/S/密度梯度分布与 Argo 的距离；
- 物理改善与 RMSE 变化的 Pareto 图。

## 9. 可行性分级

| 维度 | 判断 | 主要依据/风险 |
|---|---|---|
| 数据可得性 | 高 | 海表产品和 Argo 数据公开；主要成本是下载、配准和质量控制。 |
| 模型可实现性 | 高 | SwinOcean3D、PGTransNet 和本地博士论文均提供直接先例。 |
| 算力可控性 | 中高 | 1°热带太平洋和 16 层可在单卡上推进；0.25°全球不适合作为首版。 |
| 物理算子实现 | 中 | TEOS-10 可微实现、符号和单位需要严格测试。 |
| 论文创新性 | 中 | 简单组合已不新；必须依靠联合三维重建、严格独立验证和物理-精度 Pareto 证据。 |
| 项目按期完成 | 中高 | 前提是先复现、再加约束，不同时启动高分辨率、连续坐标和未来预测。 |

## 11. 建议的论文贡献表述

在完成实验证据前不要写“首次”。更稳健的预期贡献是：

1. 构建一个联合输出三维温盐场的 Swin 编码-解码模型；
2. 实现并验证可微的 TEOS-10 近似稳定层化约束；
3. 系统比较固定与动态多目标权重对数据精度和物理一致性的影响；
4. 在时间外推和独立 Argo 剖面上评估温跃层、异常事件及跨区域泛化。
